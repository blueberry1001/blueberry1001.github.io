# NEON RECLAIMERのページ

紹介はPersuade、履歴はRead。既存の紺色の共通ヘッダー、白系の本文、青のリンク、Interと日本語サンセリフを引き継ぐ。サイト全体の再設計はしない。

紹介は作品名・短い説明・起動リンク、実際のゲーム画面、最新更新、戦闘と周回の説明、装備ドラフト、操作方法の順。スクリーンショットを作品の証拠として扱い、数値の大きさや架空の装飾でゲームを誇張しない。

更新履歴は日付と内容を読みやすく分け、最新の内容と過去の一覧を表示する。各更新は固定URLを持つ。カードを重ねず、見出しと区切り線で整理する。スマホでは1列、動きを減らす設定では演出なし。全リンクにキーボードフォーカスを用意する。

Impeccable contextはWindows launcherのcache_directory_failedで実行不能だった。既存ソースと公開画面を直接確認し、new-workの既存世界の継承とcraft-floorを適用した。ユーザー確認済みの局所的な紹介・履歴の追加として実装する。
