# 経歴・実績の編集

`src/data/timeline.json` の1項目が年表の1件です。Reactのコードを触らずに追記・修正できます。

## 表示量

`visibility` を次のいずれかにします。実績に客観的な点数をつけるものではなく、サイト上の見せ方の設定です。

| 値 | 表示されるモード |
| --- | --- |
| `featured` | 代表的な実績・標準・すべて |
| `standard` | 標準・すべて |
| `detail` | すべて |

初期表示は「標準」。分類と組み合わせて絞り込めます。設定はURLに反映され、戻る・進む・共有ができます。
例: `/#/timeline?density=featured&category=competition`

## 記入例

```json
{
  "id": "my-event-2026",
  "year": 2026,
  "dateLabel": "9月",
  "category": "creation",
  "visibility": "standard",
  "title": "制作物や活動の名前",
  "summary": "担当したことと成果を簡潔に書きます。",
  "details": ["詳しい補足。不要なら空の配列にします。"],
  "sources": [{ "label": "本人の記事", "url": "https://example.com/" }]
}
```

- `id` は全件で重複しない名前にします。
- `year` は数値。年が分からない高校時代の活動は `null` にすると「高校在学中・時期未整理」に表示します。
- `dateLabel` は「9月」「2024年10月〜2025年3月」など、分かる精度で書きます。講座を受講開始年に配置する場合は、その旨を明記します。
- 年は新しい順。同じ年の中はJSONの配列順で表示するため、新しい出来事を先に置きます。
- `category` は `competition`（大会）/ `rating`（レーティング・認定）/ `learning`（学習・研究）/ `creation`（制作・表現）/ `community`（運営・協力）/ `education`（進学・所属）。
- `details` と `sources` は空の `[]` でも構いません。
- 主催者ページに開催概要しかない場合、参加や担当までそのページで証明されたように書かず、本人記録に基づく内容と区別してください。
- 作品との関連を編集する場合は、別ファイル `src/data/skills.json` の `workIds` を使います。

現行ホームのTimeline要約も同じデータから生成します。各年のfeatured（なければstandard）を最大4件、古い順に表示します。
保存後に `npm run build` と `npm run lint` を実行し、3種類の表示量と分類、詳細リンクをブラウザで確認してください。
