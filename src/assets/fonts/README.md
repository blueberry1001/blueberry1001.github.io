# ヒーロー用Noto Sans JP

`noto-sans-jp-hero.woff2` はGoogle Fonts公式CSS APIの `text` パラメーターで生成した、Noto Sans JPの可変フォント（ウェイト100〜900）の軽量版です。取得日: 2026-10-13。元フォント: Google Fonts v57。

取得対象の文字:

```text
競技プログラミングをメインに、ゲーム制作や動画編集など幅広く活動中。東京科学大学 / デジタル創作同好会traP
```

公式API: `https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@100..900&display=optional&text=` に上の文字列をURLエンコードして付けます。返されたCSSのwoff2を保存します。ビルドや閲覧時にGoogle Fontsへアクセスする必要はありません。

本文を変えてこのファイルにない文字が増えた場合も、OSの日本語書体で表示できます。ヒーロー全体を同じ書体に揃える場合は、更新した本文で軽量版を取り直してください。
